# gallery

A reproduction of the [WinUI 3 Gallery](https://github.com/microsoft/WinUI-Gallery), built on
`winui-svelte`. It is the project's acceptance harness: the library is finished when this app
and the real one look the same side by side on Windows 11.

```sh
pnpm --filter gallery dev
pnpm --filter gallery build    # static, fully prerendered
```
